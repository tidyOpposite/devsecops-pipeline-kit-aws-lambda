# Вартість і залишкові ресурси

Розгортання створює Lambda, API Gateway, ECR, S3 даних і журналів, CloudWatch
Logs, SQS DLQ, KMS-ключ та IAM-роль. Вартість визначають регіон, трафік,
тривалість/пам'ять Lambda, образи, версії S3, журнали, ключі та передавання даних.
Фіксовану суму або негайну нульову вартість після destroy CLI не обіцяє.

`init` не створює ресурсів; registry apply уже може створювати оплачуваний KMS.
Зупинка викликів Lambda не видаляє S3 versions, ECR layers, logs чи KMS.
S3 force_destroy і ECR force_delete вимкнено. Потрібно окремо перевірити збережені
дані, backups і образи, очистити погоджені сховища та застосувати destroy-план.

KMS видаляється за розкладом із вікном 7 днів; фіксуйте фактичну дату й повторно
перевіряйте його стан. Порожній Terraform state потребує перевірки AWS API
і пізнішої перевірки Billing. Докладніше — [виведення з експлуатації](runbooks/decommission.md).
