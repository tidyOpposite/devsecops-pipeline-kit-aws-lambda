# Повідомлення про вразливості

Не додавайте AWS credentials, токени, Terraform state, HTTP-докази або дані
workload у публічні issues. Скористайтеся приватним Security Advisory
репозиторію GitHub для чутливого повідомлення.

Вкажіть версію CLI/commit, платформу, affected command і відтворення зі
штучними значеннями. Account IDs, ARN та output редагуйте перед публікацією.
Модель довіри та відомі межі наведено в [security model](docs/security-model.md).
Випуск 1.0.1 має статус prerelease і змінює інтерфейс; cloud acceptance для нього ще потрібне.
