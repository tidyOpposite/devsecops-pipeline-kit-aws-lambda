# Напрям розвитку

Один підтримуваний сценарій: account-bound Lambda deployment зі збереженими
планами, IAM API, перевіркою health, recovery та керованим видаленням.

- Завершити cloud acceptance нового CLI на конкретному commit і wheel.
- Перевірити перехід наявного state, оновлення образу, recovery і destroy в AWS.
- Після acceptance підготувати стабільний випуск із підтвердженим обсягом підтримки.
- Розвивати діагностику й доступність основних команд без альтернативних runners.

GitHub/OIDC orchestrator, demo workload і навчальні режими до поточного продукту не входять.
